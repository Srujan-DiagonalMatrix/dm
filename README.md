# JAY Builders one-page WordPress theme

A custom classic WordPress theme recreating the supplied JAY Builders header and hero reference.

## Included

- Responsive desktop and mobile header navigation
- Full-height hero with generated clean kitchen background
- Benefit list and call-to-action buttons
- Customer testimonial card
- Keyboard-accessible menu and high-contrast control
- WordPress custom logo and primary menu support

## Use

Place this repository in `wp-content/themes/jay-builders`, then activate **JAY Builders One Page** in WordPress. Assigning a WordPress menu to **Primary Menu** replaces the built-in navigation fallback.

The front page renders the hero first, followed by any page content added in the WordPress editor.
